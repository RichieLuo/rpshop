# RPShop branding

`rpshop-logo.png` is the original generated RPShop application artwork: purple prototype panels forming an RP monogram, a mint cursor, and a pale lavender rounded plate with transparent exterior.

`rpshop-logo.svg` is a hand-authored, editable vector companion using the same composition and palette. It is intended for crisp scalable display and future brand refinements.

The Windows build script converts the PNG into a multi-resolution ICO (16, 24, 32, 48, 64, 128 and 256 pixels) in Cargo's build output directory and embeds it into `rpshop.exe`.

Palette: purple `#6129E8`, deep purple `#5422CF`, lavender `#AD8DF0`, pale plate `#F0EAFD`, mint `#A3F5BF`.

The image generation brief requested an original geometric RP panel monogram and mint cursor, a transparent exterior, flat vector-style artwork, and no words, watermark, mockup, 3D or shadows. No Axure artwork or assets were used.
