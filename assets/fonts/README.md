# Bundled font

`NotoSansCJKsc-Regular.otf` is Noto Sans CJK SC Regular from the
[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) project. It is
embedded into RPShop so Chinese text does not depend on fonts installed on the
host computer. The font is distributed under the SIL Open Font License 1.1;
see [OFL.txt](OFL.txt).
