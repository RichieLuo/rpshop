# 编辑器交互对照与验收基线

RPShop `0.5.0` · 2026-10-23。以 Windows 参考程序的官方说明和本机安装包静态实现为依据。本页分别记录参考键位与实现范围；参考表内的键位不自动代表 RPShop 已实现，发布验证见对应版本验证记录。

## 画布导航

| 输入 | 目标行为 | 证据 |
| --- | --- | --- |
| 滚轮 | 垂直滚动画布 | 官方快捷键说明；本机滚轮处理分支 |
| Shift + 滚轮 | 水平滚动画布 | 官方说明；本机分支交换横纵滚动量 |
| Ctrl + 滚轮 | 在鼠标位置缩放画布，保持指向的内容位置 | 本机 Windows 修饰键映射与缩放偏移计算 |
| Space + 拖动 | 临时平移画布，松开后回到先前工具 | 官方 Space 平移；本机空间修饰键状态 |
| Ctrl + 加号 / 减号 | 放大 / 缩小 | 官方说明及本机键盘分支，支持主键区和数字键盘 |
| Ctrl + 0 | 恢复 100% | 官方说明 |
| Ctrl + 1 / 2 / 3 | 居中画布 / 适配选择范围 / 居中选择 | 官方说明；三个操作应区分 |
| Ctrl + 9 | 移至原点 | 官方说明 |
| Page Up / Down | 分页滚动；加 Shift 改为横向 | 官方说明及本机键盘分支 |

以上公开键位依据已核对的公开快捷键说明。按键作用域应限制在画布；输入框、文件对话框和预览获得焦点时优先处理自己的输入。

本机静态实现对 Ctrl + 滚轮有更精确的证据：画布类型的滚轮处理器检查平台提供的缩放修饰键，Windows 实现明确返回 Control；没有单独 Alt 缩放分支。常规滚轮刻度 120 经过处理后传入 `0.15` 的缩放增量，目标比例为当前比例加此增量，范围钳制为 10%–1000%，并在 100% 附近吸附。高精度滚轮、连续事件与动画中间状态的最终手感尚未运行对照，不能把此静态公式当作全部设备的精确轨迹。

中键拖动画布未在本轮官方表或追踪的画布分支中确证，RPShop 将其作为额外便捷入口。不要把 H 用作参考程序的手形工具：参考键位的 H 是热点，平移用 Space。

公开映射见已核对的公开快捷键说明。Ctrl + Shift + Z 未在该 Windows 表中确证；RPShop 将其作为额外重做别名，并保留 Ctrl + Y。未实现的工具不借用其参考键位执行另一操作。

静态代码进一步确认 Delete 与 Backspace 进入同一个删除命令；Ctrl + 方向键取得右下角尺寸控制点。加 Shift 的尺寸调整分支使用偏好中的移动量，且可能受到网格与参考线吸附影响，默认较大移动量为 10。锁定切换的策略为：选择全部已锁定时全部解锁，否则全部锁定；祖先容器和背景锁定还有额外限制。

六向对齐应以首先选中的对象为参照；这与选择范围最外侧对齐不是同一个语义。参照公开元件组织说明。

## 0.5.0 实现范围

以下功能已接入编辑器。对应专项用例覆盖视图坐标、键盘事件和焦点边界；完整构建与测试结果以版本验证记录为准，不以名称存在判断交互一致。

| 能力 | 本轮实现 | 覆盖与剩余差异 |
| --- | --- | --- |
| 滚轮缩放/滚动 | Ctrl+滚轮固定鼠标所指的文档坐标；常规刻度增减 15 个百分点，范围 10%–1000%；普通滚轮纵向、Shift+滚轮横向 | 几何锚点、范围与修饰键分支有专项用例；高精度触控板、惯性和动画手感未与参考程序运行对照 |
| 平移与视图命令 | Space+拖动、额外中键拖动；Ctrl+0/1/2/3/9，以及加减号缩放 | 平移只改变视图，不修改元件位置；Page Up/Down 及全部页面导航键尚未覆盖 |
| 工具与排列键 | R/O/T/L/V；Ctrl+Shift+B/E/T；Ctrl+Alt 六向对齐；Ctrl+Shift+H/U 分布 | 未实现工具如热点不占用别的功能；对齐当前以选择范围计算，首选对象参照语义仍有差异 |
| 锁定与键盘尺寸 | Ctrl+Shift+K 全锁时解锁、否则全锁；方向键移动 1 像素，Shift 10 像素；Ctrl+方向键固定左上角改尺寸，Ctrl+Shift 10 像素 | 保留锁定、原生只读与原子编辑限制；尚无可配置移动量，参考网格/参考线的全部吸附语义未覆盖 |
| 多选与组内选择 | Ctrl 或 Shift 点击增减普通选择，Ctrl+Alt 点击选择组内元件；保留编组/解组键 | 修正 0.3.0 的 Ctrl 点击直接深选行为；复杂动态面板与全部多层容器修饰键未覆盖 |
| 桌面剪贴板 | 接收 Copy/Cut/Paste 事件；Ctrl+X/C/V 及工具栏复制/粘贴交换自有元件 JSON，可在 RPShop 窗口间粘贴；Ctrl+D 创建副本 | 复制不会直接增加元件；粘贴重新分配元件与组标识；不声明与其他编辑器元件剪贴板互通 |
| 常用编辑与焦点 | Ctrl+Shift+S 另存为、Ctrl+Shift+Z 重做别名、Backspace 删除；文本焦点优先处理文字 | 文本编辑时不触发工具切换、元件剪切删除或方向键移动；Enter 进入文字编辑、Tab/Shift+Tab 元件遍历尚未实现 |
| 页面树导航 | 原生文件夹与子页、原工程名称、蓝文件夹/灰页面图标、缩进与展开/收起、搜索、当前页高亮；页面重命名写回 | 解析、浏览与临时副本重命名/重新读取已有专项检查；原生目录结构调整及页面/文件夹增删仍禁止 |
| 左侧分区布局 | 页面、组件库、图层分别固定在各自区域内并独立滚动；两条水平分隔条上下拖动改变比例，双击恢复默认；窗口缩小时保留各区最小可用空间 | 页面树展开/收起不改变下方区域位置；比例独立保存在本机，不属于工程编辑或撤销；截图模式不覆盖用户布局 |
| 右侧属性栏 | 固定“样式/交互/说明”标签、独立滚动属性、折叠的页面信息与排列变换、窄栏坐标尺寸输入；按当前页面或组件切换内容 | 原生尺寸模式只读并保留；自适应与图片填充未实现的入口禁用并解释；“说明”只浏览状态/导入提示，尚未解析或编辑原生说明 |
| 页面尺寸与原点 | 导入 Auto、固定宽高、固定宽度和固定高度，保留原生尺寸继承；Auto 原生页以 100% 从标尺原点打开，自动轴可延伸，负坐标与远处内容可访问；原生新开默认关闭网格 | 原生尺寸目前只读；独立工程可切换四种模式；Auto 输出采用由当前可见内容推导的有限边界，固定轴保留源尺寸 |
| 原生文字布局 | 绘制、预览、HTML/SVG 使用导入的内边距、水平/垂直对齐、基本粗体与自动宽度不换行信息；恢复短高度单行标题的完整显示 | 真 RP 8 标题已有 100% 单行及源字节不变专项检查；高级/多样式排版仍有差异，SVG 仅处理显式换行，按宽度自动换行未完整实现 |
| 浏览器预览 | F5/顶部按钮在默认浏览器打开当前页；100% 默认、默认隐藏且可拖宽的目录树、搜索/展开收起、树序翻页、历史/深链接、数值缩放/适应、热点与工具栏隐藏恢复 | 0.4.2 已有浏览器工作流验收；编辑器保持可用，刷新读取最新快照，原生源页标识跨保存重编号；导出 HTML 同播放器但为当时快照。页面说明/调试控制台未实现 |
| 新建交互 | 页面载入/元件单击用例；可命名，添加、排序和删除跳转/显隐/文本动作；独立工程与RP8/11原生保存、重开、预览 | 真实egui创建/编辑/删除/撤销重做/锁保护/复制引用回归；原生副本保存重开保持新用例，其他原生高级交互只读保留；组件库展示页暂不新建 |
| 原生事件与运行场景 | 单独从源图编译事件树与有序动作链；保留实例作用域、全部动态面板状态、内联框架、选中/悬停/按下样式；原生预览不再依赖编辑模型中的单一点击动作 | 按下面的明确子集执行；不改变可编辑模型、源文件或原生保存语义；存在未实现条件/动作的用例会提示并停止该用例 |

原生文档中，剪贴板、排列和尺寸操作仍受对应元件的读写支持范围限制；未支持的结构变更不能靠快捷键绕开。

页面尺寸的参考语义来自公开页面样式说明：默认 Auto 根据元件计算页面尺寸，编辑面不受固定画板约束；静态宽度和高度可分别设置。RPShop 保留该区分，导出与预览使用可计算的有限内容边界。

播放器的逗号/句号翻页优先让位于输入框；X 隐藏、Ctrl 配合滚轮缩放、Space 平移等播放器快捷键尚未实现。它们不等同于桌面编辑器已有的键位。浏览器运行态不回写工程，刷新会重置；详情见[浏览器验收](browser-qa.md)。

## 原生预览运行范围

0.5.0 的浏览器运行器消费独立的原生场景和事件指令。源事件树中的事件、用例和动作顺序保留；母版实例使用独立运行标识，元件路径不会指向另一个实例中碰巧同名的元件。普通组和面板状态保留共同的实例作用域，使状态内事件可以访问父面板和同实例其他元件。预览通过原生写回器在内存副本中暂存已经支持的编辑，再编译场景；不需要先保存原文件。

| 原生能力 | 当前执行范围 | 限制 |
| --- | --- | --- |
| 事件与用例 | 点击、左右滑动、元件加载、页面加载，以及移动、显隐、面板状态与选中变化的内部事件；保留原用例名称，多用例提供选择菜单 | 条件判断、变量表达式及其他事件未执行；含未知条件或动作的用例整体停止并说明，其他用例仍可运行 |
| 链接与框架 | 内部页面当前窗口、新窗口/弹窗、父窗口/父框架入口；内联框架按路径和目标成对绑定，可在框架中切换本工程页面 | 外部 URL、缺失页面和循环框架显示限制提示；不按页面名称猜测失联目标，弹窗窗口特征未完全对齐 |
| 显隐与灯箱 | 显示、隐藏、切换；源动画参数、置顶、灯箱遮罩颜色与遮罩点击关闭 | 支持普通显示与灯箱，飞出/推拉等其他显示类型停止用例；保留对象原位置，不擅自居中 |
| 移动、层级和滚动 | 绝对位置、相对位移、跟随本次源移动量；置前/置后；滚动到元件 | 移动与滚动缓动仅执行无动画和线性；其他拖动/尺寸移动模式、复杂缓动停止用例；浏览器滚动插值不保证逐帧相同 |
| 动态面板 | 保留全部状态；指定状态、下一/上一、名称或一基序号、当前状态；循环、切换时显示、进入/退出动画 | 编辑画布仍只展示首状态；重复切换、推拉与固定定位等高级设置未覆盖。渐变/滑动等基本动画可运行，高级缓动和全部组合尚未逐项对照 |
| 选中状态 | `SetCheckState` 与纯文本 SetWidgetRichText/SetWidgetFormText 常量指令、同实例选中组互斥、选中/悬停/按下视觉状态 | 未实现任意函数、输入绑定或通用表达式求值 |

用户提供的 RP 8 样本含 37 个对象包，原始图有 69 条用例记录，其中 66 条包含动作。编译专项按图中顺序检查 27 条框架链接、3 条窗口链接、26 条显隐、17 条移动、6 条状态切换、3 条层级、2 条滚动和展开后的 39 条选中指令。该统计包括未被当前页面实例化的母版，不能当作每条行为都可从当前页面点击到达的证明；特别是带滑动事件的手机母版和用户“微信”页使用的手机母版并非同一个对象包。

这份样本还包含源工程本身的失联引用：30 条链接动作的目标页不在当前 16 页中；另外 12 个动作目标项引用 4 个不存在的元件标识。失联页面明确提示，失联元件项按源运行语义跳过并提示，保留同动作其他有效目标与后续动作；不把它们重定向到猜测的现有内容。跨实例歧义、未知路径结构和不支持的动作仍停止相应用例，不能把失联跳过规则用于执行未知逻辑。

单文件 HTML 与本机预览共用此运行器；SVG 仍为静态输出。Repeater 仅显示一份模板，自适应断点、变量/表达式、条件分支、复杂交互和完整版本兼容仍有缺口，不能据此宣称所有原生原型运行效果一致。

## 静态证据边界

检查对象为用户指定目录内的主托管程序集，SHA-256：`1cc3801cb9ca79ef509b17be1deecc054419df8752bf0b52c808967e08ec9bd4`。使用 REA 检查既有分析状态、`System.Reflection.Metadata.PEReader` 只读定位方法，再用本机 ILSpy 读取相关类型。没有执行参考程序、登录或修改授权。

为复查保留的中立分析文件位于忽略目录 `target/format-investigation/customer-file/`，不随产品分发：

- `component-editor.cs`：滚轮处理器 `B7Yi`、缩放函数 `w7Yr`、键盘处理、`e7Cr` 右下角尺寸调整、`LockUnlockObjects`。
- `windows-key-map.cs`：平台缩放修饰键 `JazJ` 返回 Control。
- `key-state.cs`：修饰键掩码检查及 Shift 检查。
- `selection-helpers.cs`：`TLXi` 检查选择是否全部锁定。
- `client-settings.cs`：单键快捷键启用设置及较大移动量设置。

本轮未通过运行参考程序观察高精度触控板、鼠标中键、惯性滚动、滚轮缩放动画、全部焦点切换和复杂容器选择。验证 RPShop 时需分别覆盖鼠标锚点稳定、画布局部事件消费、文本输入不触发全局编辑、连续操作的一次撤销、锁定/只读对象限制以及修饰键冲突，不能仅以快捷键名称存在为完成依据。
