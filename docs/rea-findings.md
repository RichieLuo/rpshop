## 推断与独立设计取舍

由绘图资源、动作与原型播放器脚本综合推断，最有用的产品分层是：项目/页面树、组件与图层、画布和样式检查器、交互、原型预览/导出。此分层是对静态线索的分析，不是恢复到的原架构。

rpshop 可独立采用 Rust 桌面程序、本地项目文件、无需账号的保存与编辑、基础组件绘制、移动缩放、样式编辑、页面跳转与显隐交互、HTML 原型导出。自身 JSON 格式与原创播放器是设计选择；不应将其称为 `.rp` 兼容实现。完整动态面板、repeater、表达式引擎、自适应视图和协作服务需要独立分期设计。
