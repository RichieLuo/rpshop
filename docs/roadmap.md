# RPShop 路线图

目标是让本地原型设计、保存和分享无需产品账号。当前 `0.5.0` 已建立 Rust 原生编辑器、独立工程文件、九类基础组件、默认浏览器当前页预览与 HTML/SVG 导出的工作流，并支持直接打开 RP 8 ZIP 工程及 RP 11 原生 `.rp` / `.rplib`，编辑已支持的内容并保存回原格式。已有旋转、八向缩放、对齐/分布/层级、嵌套编组/解组、图像/路径翻转、画布导航、常用快捷键、系统剪贴板、原生页面树与独立滚动侧栏。本轮在既有浏览器播放器上加入独立的原生场景/事件编译与运行子集，保留有序动作链、动态面板全部状态、框架和选中样式；编辑、运行态和原生保存边界仍然分开。RP 8/11 实文件副本已有分组与页面重命名保存/重读专项检查。开发方向参照 [REA 调查](rea-findings.md)、[元件操作对照](component-operations.md) 与 [交互对照](interaction-parity.md)；静态调查与样本解析不代表已经复原参考软件的全部行为。

## 当前边界

| 能力 | 当前状态 | 后续范围 |
| --- | --- | --- |
| 基础页面与组件 | 基础绘图、图片、样式、显隐、锁定、嵌套编组/解组和四种层级；原生文件夹/子页树保留名称、展开/收起、搜索和高亮，页面重命名写回；左侧三区独立滚动，拖动分隔条调高并本机保留；Ctrl 多选、Ctrl+Alt 深选，复制生成新标识 | 原生目录结构编辑及页面/文件夹增删仍禁止；任意面板停靠/弹出、自定义组件库管理及复杂容器样本仍待补充 |
| 画布编辑 | 拖动、多选、旋转元件命中/框选、八向缩放、中心旋转、六向对齐、水平/垂直分布、网格/吸附、撤销重做；Shift 约束移动/保持比例/15° 旋转吸附，Alt 中心缩放；组整体参与排列 | 参考线、路径编辑与连接器；首选对象对齐语义、复杂组、边界和全部修饰键仍需核对 |
| 画布导航 | Ctrl+滚轮以鼠标位置缩放，10%–1000%、常规刻度 15 个百分点；普通/Shift 滚轮纵向/横向滚动，Space 拖动与额外中键平移；Ctrl+0/1/2/3/9、加减号视图命令 | 高精度触控板、惯性、缩放动画及全部导航键尚未对照 |
| 快捷键与剪贴板 | 工具、六向对齐、两向分布、锁定、尺寸微调、另存为与重做别名；Copy/Cut/Paste 桌面事件和自有元件 JSON 跨 RPShop 窗口交换；文本焦点保护 | Enter 文字编辑、Tab 元件遍历、其他工具/容器键位、可配置移动量及全部吸附规则；不声明其他编辑器元件剪贴板互通 |
| 页面尺寸与文字显示 | 导入 Auto、固定宽高与单轴尺寸，保留继承；Auto 原生页初始 100% 标尺原点与可延伸自动轴；属性栏显示实际模式；文字保留内边距/对齐/基本粗体/自动宽度 | 原生尺寸编辑、完整页面样式编辑、高级多样式排版及 SVG 自动按宽换行仍有缺口 |
| 图像/形状翻转 | 图像实际像素翻转；保留可用 ControlPoints 的矢量形状反射路径/贝塞尔手柄并反向调整对象旋转；直线导出、显示和命中使用实际端点 | 尚不将无可用路径的形状自动转换；不以整元件字形负缩放替代，继续核对高级文字和混合元件 |
| 点击交互 | 页面载入和元件单击可新建命名用例，添加/排序/删除跳转、显隐和文本动作；RP8/11新增用例保存重开仍可编辑，其他原生用例保留；预览另按源事件树编译点击/加载/滑动及内部事件，有序执行框架/页面链接、显隐/灯箱、常量移动、层级、滚动与选中状态；多用例显示原名称菜单 | 原生条件、变量表达式、延迟及未知动作停止对应用例；原有高级用例尚只读，条件编辑和全部事件未实现；移动/滚动仅无动画或线性缓动 |
| 动态面板 | 编辑画布显示首状态；原生浏览器预览保留全部状态及局部子组件，可执行指定/前后/名称或序号状态切换、循环、切换时显示和基本进入/退出动画 | 状态编辑、重复切换、推拉、固定定位及全部动画/滚动组合仍待补充 |
| Repeater | 导入模板作为显示，保留原始记录；未运行数据行为 | 数据表、行事件、排序、筛选和分页 |
| 变量与表达式 | 未实现；输入框只是预览控件 | 全局/局部变量、表达式求值、输入绑定和条件判断 |
| 自适应视图 | 导入默认视图，保留原始记录；现有 Auto/固定尺寸模式没有断点和运行视图切换 | 断点、视图继承、各视图样式与布局规则 |
| `.rp` / `.rplib` 兼容 | RP 8 ZIP/分页对象包和 RP 11 原生容器读写；直接打开，`Ctrl+S` 保存已支持的编辑及页面重命名；保留未编辑部件，提示限制并核对源文件变化。样本覆盖 RP 8 `.rp`、RP 11 `.rp`/`.rplib`，实文件副本覆盖分组与页面重命名保存/重读 | 原生目录结构编辑仍禁止；RP 9/10 与 RP 8 `.rplib` 尚无验证覆盖；母版缩放后重开自然尺寸、高级文字/独立文字旋转、复杂组件及全量原厂互操作仍未验证 |
| `.rpteam` / `.rpteamlib` 兼容 | 未实现团队工程及团队组件库导入 | 取得可验证样本，研究本地结构和可独立导入的范围 |
| 云端与协作 | 未实现 | 本地优先；协作或托管如有需要，应作为明确可选能力独立设计 |
| 预览与导出 | F5/按钮经本机内存 HTTP 在默认浏览器打开当前页；编辑器保持可用，刷新读取最新快照，源页面标识跨原生保存重编号；100% 默认、可调目录树、DFS 翻页/搜索/历史/深链接/缩放/适应/热点/隐藏恢复；内联框架可加载本工程页面，原生全部状态与已支持动作在独立运行器执行；单文件 HTML 共用，SVG 静态 | 运行态不回写工程，刷新重置；源失联页明确提示，失联元件目标跳过并保留有效目标与后续动作；页面说明/调试控制台、条件、变量、复杂动画/框架窗口语义尚未完整实现；SVG 按宽度自动换行仍不完整 |

## 优先顺序

1. 稳固本地工作流与原生编辑：持续检查保存/恢复、撤销、组件引用、图片与导出的一致性；增加真实 `.rp` / `.rplib` 样本，对照检查读写差异、未编辑数据保留与源文件冲突处理。
2. 提高编辑效率：继续补齐元件编辑/遍历和其他常用键位，核对全部导航与焦点边界；扩大编组/解组及翻转类型，补充参考线、首选对象对齐和组件复用，并在验证读写后逐步开放原生目录编辑。
3. 扩展原型运行和编辑：在已支持的原生事件/动作链与多状态预览上，补条件、变量/表达式、延迟和更完整动画，扩展交互编辑事件与动作，随后评估 repeater 和自适应视图。每种能力同时核对目标解析、实例隔离、动作次序、失联引用及不支持逻辑的提示。
4. 在取得样本后评估 RP 9/10、其他版本、团队文件与可选协作，以样本和行为测试界定支持范围。

本路线图描述功能缺口和顺序，不承诺完成日期。无可用路径形状的转换、复杂容器/动态面板状态、高级交互、高级文字/独立文字旋转、母版缩放后重开自然尺寸语义及全量原厂互操作仍有缺口或未验证，不能宣称操作已完全对齐。开发新功能时同步更新支持边界，避免把基础容器、固定尺寸页面或浏览器缩放描述为完整动态面板与自适应布局。
