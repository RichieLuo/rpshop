# HTML 原型浏览器验收

## 0.5.0 原生运行与新建交互

2026-10-23，最新 debug 构建在真实 Microsoft Edge 完成 **10 个 REA 场景、186 个声明动作及 196 步**；16 次本机 HTML 请求全部 200，外部请求、脚本错误、console 消息及丢失事件均为 0。另用 Playwright 实际鼠标操作完成 4 次滑动和 2 次准备点击，仅 1 次本机请求；这是自动指针操作，未验证物理触屏。

- 实际 RP8 文件：四页签切换、选中样式和指示条位置，两个筛选入口的移动/显示/滚动与取消/完成，七个浮层遮罩及点外关闭，十一项菜单之间清除旧选中状态；失联框架目标明确提示，后续选中动作仍执行；多目标关闭中缺失的元件被跳过，有效目标仍关闭。
- 独立自建原生文件：页面与框架内跳转、框架中返回、原生纯文本设置、左右滑动与 500ms 状态动画；20px 和 1100ms 手势不切换。业务文件中的滑动源事件位于未实例化母版，手势验收使用独立原生文件。
- 新建交互：独立 JSON 工程的页面载入、多动作显隐/文本、往返跳转；新建事件保存成原生文件后重新打开，载入和点击动作均执行；点击复选框文字不重复执行动作；页面载入后自动跳转保持内容/页名一致，双向载入跳转循环会停止并提示，播放器继续可操作。

公开的[脱敏证据](native-preview-qa-evidence.json)仅包含自建六场景的 63 动作、69 步及四次手势结果。业务证据只留在忽略目录；[原生预览截图](screenshots/native-preview.png)与[交互编辑截图](screenshots/interaction-editor.png)均为自建内容，已实际查看。所有七个 QA 主机均已关闭。

播放器和新建交互的支持范围见[交互对照](interaction-parity.md)。原有高级用例、条件/变量、Repeater、自适应断点及全部缓动仍未完整覆盖，不表示任意原生工程完全一致。下方保留历史版本记录。

### 网络与错误

三个场景的捕获均报告完整，事件没有丢弃或预算截断。在所捕获的场景窗口内，**外部来源请求为 0，JavaScript 页面错误为 0**。网络事件记录的是回环地址上的 HTML 文档加载；这些结果不代表对浏览器全部后台流量的系统级监控。

测试时唯一的控制台错误是浏览器请求本地 `http://127.0.0.1:18753/favicon.ico` 得到 404。它属于本地站点图标探测，不是外部请求或交互脚本错误。之后已在导出器中加入内嵌 data favicon，并重新生成示例；该修正未重新运行浏览器验收。
