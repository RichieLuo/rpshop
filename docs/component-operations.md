# 元件操作对照与验证清单

RPShop `0.4.2` · 2026-10-23。本文分别记录参考程序的静态证据和 RPShop 的实现范围，不能把符号、资源名称当作已经运行验证的行为。本文不包含用户工程名称或业务内容。

## 静态证据

检查对象为用户指定安装目录内的主托管程序集，SHA-256 为 `1cc3801cb9ca79ef509b17be1deecc054419df8752bf0b52c808967e08ec9bd4`。使用 `System.Reflection.Metadata.PEReader` 只读解析字段、方法及常量，使用本机反编译器读取相关设置、编辑与键位类型；没有加载或执行目标程序集。

| 操作 | 已观察的证据 | 证据范围 |
| --- | --- | --- |
| 移动/拖动 | `MoveSelectedItem`、`MoveSelectedItemsTo` 方法及 `MoveBehavior.Drag/DragX/DragY` | 证明有相关操作，拖动约束与复制修饰键需运行核对 |
| 缩放 | `GeometryEditType.Resize`；位置枚举包含四边及四角 | 缩放能力已观察；不能仅由枚举证明有八个可拖控制点 |
| 旋转 | `PName.ROTATION` 常量为 50；`TEXT_ROTATION` 为 51；另有 `Rotate` 方法 | 原生字段 ID 已精确确认，交互手柄及吸附规则需运行核对 |
| 六向对齐 | 程序资源标识 `align_left/center/right/top/middle/bottom` | 六个命令已观察，混合旋转元件的边界算法需核对 |
| 两向分布 | `distribute_horizontally`、`distribute_vertically` | 两个命令已观察，按间隙还是中心计算需核对 |
| 四种层级 | `ZOrderEditAction` 的 `BringToFront/SendToBack/BringForward/SendBackward` | 四个原生编辑动作已观察 |
| 编组/解组 | `Group` 方法、`AssignGroup_Fired` 编译器生成符号，以及 `ungroup/Ungroup` 资源标识 | 命令存在；嵌套组、组内选择与解组变换需核对 |
| 图像水平/垂直翻转 | `FlipImageHorizontal_Fired`、`FlipImageVertical_Fired` 的 IL 绑定及后续图像编辑流程 | 生成同尺寸翻转位图并更新图像属性，保留元件位置、尺寸与角度 |
| 形状水平/垂直翻转 | `FlipHorizontal_Fired`、`FlipVertical_Fired` 的 IL 绑定、矢量编辑及控制点反射流程 | 水平控制点为 `(1-x,y)`、垂直为 `(x,1-y)`；贝塞尔手柄同步变换，并反向调整对象旋转；未观察到字形负缩放 |
| 框选/多选 | 官方快捷键表说明 Ctrl 普通多选、Ctrl+Alt 深选，V 框选工具 | 修饰键映射已确认；复杂容器边界与点击顺序仍需运行核对 |
| 方向键与修饰键 | 官方快捷键表与本机键盘分支；`ClientSettings.ShiftNudge` 默认注解为 `10.0`；尺寸调整使用右下角控制点 | 普通方向键移动、Ctrl 调整尺寸、Shift 增大步长；自定义移动量及吸附行为仍需对照 |

旋转字段的精确坐标：Field token `0x04003253`（RID 12883），声明类型 `PName`（此处省略命名空间），常量类型 `Int32`、原始 Blob `32 00 00 00`，即十进制 `50`。文本旋转字段为 `0x04003254`，Blob `33 00 00 00`，即 `51`。`DOAName` 是另一个枚举，不能据名称相似混用。

参考程序中的“图像翻转”和“形状翻转”是两种数据操作。形状路径改变归一化控制点及对象旋转，图像路径改变图像像素；已追踪分支未改写文字内容或为字形增加镜像变换。纯文本选择、矢量图像及嵌套组的精确适用范围仍需运行核对，不能用整个元件的负缩放替代两种命令。

上述编辑操作接入撤销/重做。独立工程的旋转、组合和矢量路径字段兼容旧文件缺省值；原生旋转映射使用字段 50。图像翻转写回图像内容，路径形状翻转写回控制点及角度，两者不通过为整个元件设置负缩放来模拟。

0.4.2 的 F5 预览改为默认浏览器当前页，编辑、撤销/重做、取消拖动和保存后刷新会读取最新内存快照；原生源页面标识跨保存重编号。HTML 导出使用同一播放器但为当时快照，原型运行态不回写工程。播放器与高级原生交互的边界见[浏览器验收](browser-qa.md)。

## 原生兼容与剩余验证

已有 RP 8 ZIP 工程容器与嵌套分页对象包兼容，覆盖一份本机真实工程；RP 8 和 RP 11 实文件副本已完成编组保存后重新读取的专项检查。本轮补充原生页面树与页面重命名写回，并使用临时副本核对，不记录用户工程名或业务内容。已支持的编辑按原格式写回，不要求另存为 `.rpshop`，不将旧版容器升级为 RP 11 容器。原生目录结构调整、页面或文件夹增删仍禁止。现有样本范围是 RP 8 `.rp`、RP 11 `.rp` / `.rplib`；RP 9/10、RP 8 `.rplib` 尚未验证。

无可用路径形状的转换、复杂容器/动态面板状态、高级交互、高级文字排版/独立文字旋转、母版实例缩放后重开的自然尺寸语义，以及全量原厂互操作仍有缺口或未验证。常用快捷键与画布导航的证据及边界见[交互对照](interaction-parity.md)；全部工具键位、边界命中、缩放跨锚点、首选对象对齐与复杂分组行为仍需继续核对，不宣称所有元件操作已完全一致。
