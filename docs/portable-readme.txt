RPShop 0.6.0 · Windows x64

双击 rpshop.exe 启动。
按 F5 可在默认浏览器中预览当前页。

第一次启动会显示可编辑的欢迎示例。通过“文件”菜单新建、打开和保存工程。
可打开 RP 8 ZIP 格式 .rp 工程、RP 11 原生 .rp 工程和 .rplib 组件库，也可把文件拖入窗口。
已有一份真实 RP 8 工程的兼容检查；RP 9/10 和 RP 8 .rplib 尚未验证，不声明支持。
RP 8 和 RP 11 实文件副本已完成编组保存后重新读取的专项检查。
原生页面树保留真正的文件夹和子页，蓝色文件夹、灰色页面图标区分节点，支持展开/收起、搜索与当前页高亮。
显示原工程页面名；页面重命名可直接保存回原文件，已使用临时副本核对。
左侧页面、组件库、图层是独立滚动区域，展开目录不会再将下方区域挤走。
上下拖动两条分隔条调整区域高度，双击分隔条恢复默认；比例保存在本机，不修改工程。缩窄侧栏时组件库自动换列。
打开后显示可识别的页面与基础组件，并提示还原和编辑限制，请核对画面与交互。
修改支持的内容后，Ctrl+S 直接保存回原来的 .rp / .rplib，无需先转换格式。
RP 8 写回同一 ZIP/分页对象包格式，RP 11 写回同一原生容器；不升级或转换文件格式。
原生保存保留未编辑部件，采用临时文件与原子替换；原文件被其他程序修改时会拒绝覆盖。
新建工程默认使用独立的 .rpshop 格式；另行转换为此格式是可选工作流。
暂不支持 .rpteam / .rpteamlib 团队文件及未验证的其他 Axure 文件版本。

组件库提供 87 个条目，分为基本元件、表单与菜单、标注、流程图、常用图标，支持搜索和分类筛选。
新增单选按钮、多行文本域、下拉列表和列表框，预览为真正可操作的表单。
表格、菜单和树是可解组的组件组合；动态面板状态编辑、中继器、框架新建与关联快照尚未实现。
在 .rp 工程中新增四类表单时，该文件须已含同类原生模板；.rplib 仍不支持新增库条目，已有表单可编辑。独立 .rpshop 工程不受模板限制。
examples/library.rpshop 和 library.html 提供可编辑、可预览的原创组件画廊。

基本操作：
1. 点击左侧组件或将其拖入画布。
2. 选中组件，在右侧修改位置、尺寸、角度、文字与颜色；八个缩放手柄调整大小，上方圆形手柄旋转。
3. 所有基础类型均支持中心旋转，直线可斜向；空白画布拖动框选，Ctrl 或 Shift+点击增减多选。
4. 移动时按 Shift 约束主轴；缩放时 Shift 保持比例、Alt 从中心缩放（可组合）；旋转时 Shift 按 15° 吸附。
5. 多选后可进行六向对齐、水平/垂直分布（至少三个组件），或置顶、置底、上移一层、下移一层。
6. Ctrl+G 组合、Ctrl+Shift+G 解开一层；支持嵌套组合，Ctrl+Alt+点击选择组内元件。
7. 普通选中组后，对齐、分布和层级调整以组为整体单位；复制组会分配新组标识。
8. 图像翻转实际修改像素；已保留可用 ControlPoints 的形状可翻转路径和贝塞尔手柄并反向调整角度。
   直线的显示、导出和命中使用实际端点；不以整个元件的字形负缩放替代翻转。
9. 在右侧“交互”点击“新建交互”和“添加动作”：空白画布创建页面载入事件，选中元件创建单击事件。
   支持命名用例、多动作排序/删除，动作包括页面跳转、显隐切换、设置文本；RP8/11保存重开仍可编辑新增用例，其他原生用例保留。
   按F5或“预览原型”打开默认浏览器当前页，编辑器保持可用；组件库展示页暂不新建事件。
10. Ctrl+S 保存，Ctrl+Shift+S 另存为；Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。
11. Ctrl+X/C/V 剪切/复制/粘贴，通过系统剪贴板在 RPShop 窗口间交换元件；Ctrl+D 直接创建副本。
    工具栏“复制”只复制，点击“粘贴”才插入组件。元件剪贴板不声明与其他编辑器互通。
12. 方向键移动 1 像素，Shift+方向键移动 10 像素；Ctrl+方向键固定左上角调整尺寸 1 像素，Ctrl+Shift+方向键 10 像素。
13. Delete 或 Backspace 删除；Ctrl+Shift+K 切换锁定：选择全锁时解锁，否则全部锁定。
14. R/O/T/L/V 选择矩形/椭圆/文字/直线/选择工具；Ctrl+Shift+B/E/T 也可选择矩形/椭圆/文字。
15. Ctrl+Alt+L/C/R/T/M/B 六向对齐，Ctrl+Shift+H/U 水平/垂直分布。
16. 滚轮上下滚动画布，Shift+滚轮左右滚动；Ctrl+滚轮以鼠标位置缩放，范围 10%–1000%，常规每格增减 15 个百分点。
17. Space+拖动临时平移画布；另提供中键拖动。Ctrl+加号/减号放大/缩小，Ctrl+0 恢复 100%。
18. Ctrl+1 居中画布，Ctrl+2 适配选择范围，Ctrl+3 居中选择，Ctrl+9 移至原点。
19. 导出单文件 HTML 后，可直接在浏览器中演示；SVG 为当前页面的静态导出，两者均保留旋转和直线斜向几何。

文本框获得焦点时优先编辑文字，不触发画布的工具切换、剪切删除或移动。
右侧固定“样式 / 交互 / 说明”标签，下方属性独立滚动；页面名称在“页面信息”中修改。
组件角度与排列在“排列与变换”中；窄属性栏仍可完整输入坐标与尺寸。
原生页面尺寸模式只读，显示 Auto、单轴固定或固定宽高；原始设置在保存时保留。
原生 Auto 页以 100% 从标尺原点打开，自动轴可延伸到负坐标和远处内容。
新打开原生文件默认关闭网格，可在工具栏开启；独立工程可在右侧切换四种尺寸模式。
预览、HTML、SVG 的自动轴由当前可见内容推导输出边界，固定轴保留源尺寸。
原生文字保留内边距、水平/垂直对齐、基本粗体及自动宽度不换行设置，改善单行标题裁切。
“说明”当前浏览页面/组件状态和导入提示，原生说明内容尚未解析或编辑。

浏览器预览：
默认以 100% 显示当前页，目录默认隐藏；点击顶部页名打开文件夹/子页树。
目录支持搜索、展开/收起、当前页高亮，默认宽度 220 像素，可拖动右边缘调整。
上一页/下一页按页面树顺序浏览，逗号/句号也可切页；在输入框中打字时不触发翻页。
支持浏览历史前进/后退、页面深链接、25%–400% 数值缩放、适应宽度、完整适应、热点与工具栏隐藏/恢复。
修改工程后刷新浏览器或点播放器“重新载入”，读取最新的未保存内容；撤销、重做、取消拖动和保存后也会更新预览快照。
原生文件保存后即使内部数值 ID 重排，刷新仍通过源页面标识定位原来的逻辑页。
浏览器中的输入、勾选、显隐和文本变化只是运行态，不回写编辑工程；刷新会重置运行态。
本机预览只提供内存 HTML，不把工程或 HTML 写到原文件旁。关闭编辑器或成功切换工程时，旧预览服务停止。
导出单文件 HTML 使用同一个播放器，可直接在浏览器中打开；它是导出时的快照，刷新不会读取后续编辑内容。
原生预览保留全部动态面板状态和实例层级，执行已支持的点击/加载/滑动、选中样式、连续动作、浮层遮罩、移动、状态切换、层级、滚动及内部页面/框架跳转。
失联页面会明确提示，缺失元件只跳过对应目标；含不支持条件或动作的用例停止并说明。运行态不回写工程。
页面说明/调试控制台、变量/表达式、Repeater数据、自适应断点、推拉布局和全部缓动仍未完整实现；编辑画布的动态面板仍显示首状态。

图层右侧两列：
“显示”列的眼睛切换组件显示/隐藏，隐藏不会删除组件。
“锁定”列的锁切换可否编辑；锁定后不能移动、缩放或修改，解锁后恢复编辑。
按钮悬停会显示说明。点击图层名称用于选择，点击眼睛或锁直接切换状态。

examples/welcome.rpshop：可重新编辑的两页示例。
examples/welcome.html：可直接用浏览器打开的交互示例。
examples/welcome.svg：静态页面导出示例。
examples/operations.rpshop：旋转、直线和组合的操作示例。
examples/interactions.rpshop：页面载入、连续显隐/文本和跳转的新建交互示例。

正常退出和定时自动保存会保留本机会话。会话与恢复文件保存在用户配置/数据目录，
不是 rpshop.exe 所在目录；正式工程请通过“保存”选择自己的文件位置。

目前提供基础原型工作流，原生编辑属于部分兼容；样式、布局、层级与高级交互可能有差异。
支持嵌套编组/解组、图像翻转和已保留路径的形状翻转；尚不自动转换无可用路径的形状。
操作尚未完全对齐参考编辑器，详细实现和测试覆盖见项目文档。
Enter 编辑、Tab/Shift+Tab 元件遍历、全部工具/容器修饰键与可配置移动量尚未覆盖。
高精度触控板手感、惯性滚动及参考缩放动画尚未完成运行对照；中键平移是 RPShop 的额外便捷入口。
完整动态面板、Repeater、变量表达式和自适应视图尚未实现，不支持的编辑会按提示处理。
复杂容器/动态面板状态、高级交互、高级文字排版/独立文字旋转仍有缺口或未验证。
SVG 文字保留显式换行，按宽度自动换行尚未完整实现。
母版实例缩放后重开的自然尺寸/缩放语义及全量原厂互操作仍需验证。
原生保存成功后会重新读取文件并重置当前撤销历史；原生页面/文件夹增删、目录结构调整、组件库结构等暂不支持。
未将本机真实工程的文件名或业务内容加入发布包。
