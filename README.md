# RPShop

用 Rust 编写的桌面原型工具，采用 `eframe/egui` 原生桌面界面，支持原型编辑、浏览器预览和 HTML/SVG 导出。

当前版本为 `0.6.0`，提供可编辑、可点击、可导出的基础原型工作流。可直接打开 **RP 8 ZIP 格式 `.rp` 工程，以及 RP 11 原生 `.rp` 工程和 `.rplib` 组件库**，编辑支持的内容后按 `Ctrl+S` 写回原格式，无需先转换为 `.rpshop`。已提供画布导航、常用快捷键、系统剪贴板和原生页面树；浏览器预览保留页面树、缩放、浏览历史与热点；本轮补充原生连续动作、动态面板全部状态、选中样式、浮层与内部框架运行时。原生编辑仍属于部分兼容，界面会列出还原与编辑限制。新建工程默认使用独立的 `.rpshop` JSON 格式。只读 REA 调查记录在 [调查报告](docs/rea-findings.md)，旧版容器结构见 [兼容调查](docs/native-compat-fix.md)，后续范围见 [路线图](docs/roadmap.md)。

## 启动

当前便携程序位于 `dist/RPShop-0.6.0-windows-x64/rpshop.exe`，整包为 `dist/RPShop-0.6.0-windows-x64.zip`。请使用该版本目录中的程序，或同根目录的 `dist/rpshop.exe`。

Windows 构建需要 Rust 1.89 或更新版本、MSVC C++ 构建工具与 Windows SDK。在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

已配置好 Rust/MSVC 环境时，也可直接运行：

```powershell
cargo run --locked
```

首次启动显示包含“工作台”和“组件与交互”的欢迎示例。文件菜单可打开欢迎示例、新建工程、打开工程、保存或另存为；也可把文件拖入窗口，或用工程路径启动：

```powershell
cargo run --locked -- .\examples\welcome.rpshop
cargo run --locked -- .\my-project.rp
```

## 当前功能

- 页面：独立工程可添加、删除、切换、重命名及设置尺寸与背景。原生文档按真正的文件夹与子页层级浏览，蓝色文件夹与灰色页面图标区分节点，支持缩进、展开/收起、搜索和当前页高亮；显示原工程的页面名称，支持页面重命名写回。
- 左侧布局：页面、组件库和图层分成三个独立滚动区域。展开或收起页面树不会推动下方区域；拖动两条水平分隔条可调整各区高度，双击恢复默认比例。区域比例在本机保留，不写入工程；缩窄侧栏时组件库自动换列。
- 组件库：按“基本元件、表单与菜单、标注、流程图、常用图标”五组浏览，支持中英文关键词搜索、分类筛选、点击添加和拖入画布。包含标题、段落、链接、按钮与矩形样式、占位符、热区、便签、编号标记、多边形、箭头、流程图形和原创线图标。样式预设复用基础类型，库条目数量不等于底层组件类型数量；具体范围见 [组件库对照](docs/widget-library-parity.md)。
- 表单与组合：单行输入框、多行文本域、复选框、单选按钮、下拉列表和列表框使用各自的真实控件类型，预览与 HTML 导出可输入或选择；下拉/列表选项每行一个，单选按钮可指定互斥组，默认按组件名称分组。表格、横向/纵向菜单和树为可解组编辑的组件组合，尚无专用行列、子菜单或可折叠树模型。
- 画布：单选、Ctrl/Shift 多选和支持旋转元件的框选；拖动移动、八向缩放、中心旋转、方向键微调、网格与吸附。Ctrl + 滚轮以鼠标位置为锚点缩放，普通滚轮上下滚动，Shift + 滚轮左右滚动；Space + 拖动临时平移，另提供中键拖动。缩放范围 10%–1000%，常规滚轮每格增减 15 个百分点。所有基础元件类型均支持旋转，直线可斜向显示和编辑。
- 页面尺寸模式：保留原生 Auto、固定宽高、仅固定宽度或仅固定高度。原生 Auto 页以 100% 从标尺原点打开，编辑区域可延伸到负坐标和远处内容；新打开原生文件默认关闭网格，可在工具栏开启。独立工程可在右侧切换四种模式；原生尺寸设置目前只读。
- 操作修饰键：移动时按 Shift 约束主轴；缩放时按 Shift 保持比例、按 Alt 从中心缩放，可组合使用；拖动旋转手柄时按 Shift 吸附到 15°。
- 样式与图层：位置、尺寸、角度、文字、字号、颜色、圆角、不透明度；显隐、锁定、六向对齐、水平/垂直分布，以及置顶、置底、上移一层、下移一层。
- 右侧属性：固定的“样式 / 交互 / 说明”标签按当前页面或组件显示内容，属性独立滚动。“样式”显示实际页面尺寸模式，页面名称在“页面信息”中；组件的角度与排列命令收在“排列与变换”。“说明”目前浏览组件状态与导入提示，尚不编辑原生说明。
- 编组：支持嵌套组合/解组，`Ctrl+G` 组合、`Ctrl+Shift+G` 解开一层，`Ctrl+Alt` 点击选择组内元件。普通选择将组作为对齐、分布和层级调整的整体单位，保持组内相对位置与顺序。
- 翻转：图像水平/垂直翻转实际修改像素；已保留可用 `ControlPoints` 的矢量形状可反射控制点和贝塞尔手柄，并反向调整对象角度。直线显示、导出和命中使用实际路径端点。
- 编辑：剪切、复制、粘贴、创建副本、删除、撤销/重做；接入桌面系统剪贴板事件，元件以 RPShop 自有数据在多个窗口之间复制粘贴，复制组会生成新的组标识。“复制”保留原组件，“创建副本”直接生成新组件。文本输入焦点优先，避免编辑文字时误操作画布。本机会话恢复与定时恢复备份；`Ctrl+S` 将工程写入选定文件。
- 文件：打开 RPShop 工程，或直接打开已验证样本覆盖的 RP 8 ZIP 工程和 RP 11 `.rp` / `.rplib`；支持的原生编辑可保存回原格式，并提示还原与编辑限制。
- 交互编辑：“交互”面板提供“新建交互”和“添加动作”。空白画布可创建页面载入事件，选中元件可创建单击事件；用例可命名，多个动作可排序、删除，支持页面跳转、切换目标元件显隐和设置文本。新建事件参与撤销/重做、会话恢复和 HTML 导出；RP 8/11 新建用例写回原文件，重开仍可编辑，其他原有复杂交互保留。组件库展示页暂不新建事件。
- 预览：`F5` 或顶部“预览原型”在默认浏览器打开当前页，编辑器保持可用。播放器默认 100%，可打开隐藏的文件夹/子页目录，搜索和展开/收起、按页面树顺序翻页、前进/后退、缩放或适应窗口、显示热点及隐藏/恢复工具栏。原生预览支持点击连续动作、选中/取消选中及互斥选中组、显示/隐藏/切换、浮层遮罩关闭、绝对/相对/跟随移动、动态面板状态切换和左右滑动、层级与滚动，以及本工程内页面和框架跳转。失联页面明确提示，后续独立动作继续执行；输入与运行态不回写工程。
- 导出：整个工程导出为单文件交互 HTML，使用与浏览器预览相同的播放器；导出文件是当时快照，可直接在浏览器中打开。当前页可导出静态 SVG，两种导出均保留旋转、直线斜向几何和预设矢量路径；SVG 中的表单为静态外观。自动轴按当前可见内容推导输出边界，固定轴保留源尺寸。图片嵌入工程与导出文件。

组件库中的“容器”目前是基础画布组件；原生预览另保留已导入动态面板的状态和子组件层级，编辑画布仍展示首状态。新建动态面板及状态编辑、中继器数据行为、内联框架与关联快照编辑仍未提供；原创常用图标集尚未覆盖原厂库的 920 项。流程图提供静态造型，部分弧线和圆角为折线近似，连接点和箭头没有自动吸附、跟随对象的连接器行为。表单提供原型演示行为，没有业务数据提交功能。

形状翻转只作用于已保留的可用路径，尚未实现将其他形状自动转换为矢量路径；图像翻转与形状翻转均不以通用字形负缩放代替。当前操作并未完整对齐参考编辑器，详细范围与测试覆盖见 [元件操作对照](docs/component-operations.md) 和 [交互对照](docs/interaction-parity.md)。

## 打开 RP 文件

按 `Ctrl+O` 选择 `.rp` / `.rplib`，或把文件拖入窗口。程序读取原生文件的索引和组件数据，在画布中显示可识别的页面与基础组件。打开后请查看还原范围提示，再核对画面和交互。修改支持的内容后按 `Ctrl+S`，会保存到原来的 `.rp` / `.rplib` 文件，不要求转换格式。

原生保存保留未编辑部件的原始字节。RP 8 保留 ZIP 容器及嵌套分页对象包，更新被编辑的流；RP 11 更新被修改的部件及索引，均不升级或转换成另一种文件格式。写入使用同目录临时文件与原子替换；如果原文件已被其他程序修改，会拒绝覆盖并提示重新打开。

目前原生写回支持页面重命名、基础元件的文字、位置、尺寸、旋转、样式、显隐、锁定、嵌套组，以及已支持的组件增删、图像/路径翻转和页面跳转，具体取决于版本及元件类型。RP 8 和 RP 11 实文件副本已完成分组保存后重新读取的专项检查，本轮页面树浏览与页面重命名也以临时副本核对。原生页面或文件夹增删、目录结构调整、画板尺寸修改、跨页面移动现有组件、复杂容器结构重排、组件库结构修改等尚未支持；这些操作会在写入前明确拒绝。原生保存成功后会重新读取文件建立检查点，并重置当前撤销历史。全量原厂编辑器互操作尚未验证。

新增单选按钮、文本域、下拉列表和列表框写回 `.rp` / `.rplib` 时，当前文件需已有同类原生对象可作为模板；没有模板会明确拒绝该次保存。独立 `.rpshop` 工程没有此模板限制。新增基础容器仍不支持原生写回，组合预设也不会自动转换成原厂的专用表格、菜单或树对象。

| 文件 | 当前支持 |
| --- | --- |
| `.rpshop` / RPShop `.json` | 打开、编辑与保存本工具工程 |
| RP 8 ZIP 格式 `.rp` | 直接打开，编辑支持的内容并保存回同一 ZIP 原生格式；已有真实工程样本检查 |
| RP 11 `.rp` | 直接打开，编辑支持的内容并保存回 `.rp`；部分兼容 |
| RP 11 `.rplib` | 直接打开，编辑支持的内容并保存回 `.rplib`；部分兼容 |
| `.rpteam` / `.rpteamlib` | 暂不支持团队工程及团队组件库 |
| RP 9 / RP 10 及其他版本 | 未验证，不声明支持；按文件内部格式和版本识别 |
| RP 8 `.rplib` | 尚未单独取得验证样本 |

复杂容器、动态面板状态、Repeater、自适应视图、高级交互和组件复用尚未完整实现。编辑画布中的原生动态面板仍展示首状态，预览则重建全部状态并执行支持的连续动作与切换；Repeater 仍采用一份模板、自适应采用默认视图。条件、变量与非字面表达式、拖拽驱动移动、推拉布局、面板自动循环、数据筛选和外部网页框架未实现；包含不支持动作的用例会明确提示并停止该用例，避免只执行半条链。组件库预览仍为静态展示。原生文字已保留内边距、水平/垂直对齐、基本粗体和自动宽度不换行设置；高级排版与独立文字旋转仍有差异。SVG 文字目前保留显式换行，尚未完整实现按宽度自动换行。母版实例缩放后重新打开的自然尺寸/缩放语义仍需核对。样式、层级与布局也可能存在差异，打开时会提示已识别的限制。未显示或未支持编辑的原始数据不代表可以在 RPShop 中完整操作。

如果需要另外生成 RPShop 工程，也可选用命令行转换：

```powershell
cargo run --locked -- --import .\my-project.rp .\my-project.rpshop
```

此可选转换命令的输出文件须使用 `.rpshop` 扩展名，会报告页面数、组件数和限制；它不替代原生打开和保存。原生文件读取上限为 256 MiB，单个部件解压上限为 64 MiB；画布内容还需满足 RPShop 工程本身的大小与组件数量限制。

## 图层右侧按钮是什么意思

图层列表右侧有“显示”和“锁定”两列，按钮采用绘制的眼睛与锁图标，悬停可查看文字说明。

- **眼睛**：控制该组件在画布和预览中显示或隐藏。隐藏保留组件，再点一次即可显示。
- **锁**：控制该组件能否编辑。锁定后不能移动、缩放或修改，解锁后恢复编辑。

点击图层名称用于选择组件；点击眼睛或锁直接切换对应状态。

## 快速制作一个原型

1. 在左侧添加页面，点击空白画布后在右侧“样式”中设置尺寸，展开“页面信息”修改页名。原生文档保留原尺寸模式，页名可修改。
2. 从组件库添加组件，拖动调整位置；在右侧“样式”中编辑内容与外观，展开“排列与变换”调整角度或排列。
3. 打开右侧“交互”，点击“新建交互”和“添加动作”。选中按钮时创建单击事件，选空白画布时创建页面载入事件；指定目标页或元件，可继续添加并排序多个动作。
4. 点击“预览原型”或按 `F5` 在默认浏览器验证当前页，切回编辑器继续修改，再刷新浏览器查看最新内容。
5. 新建工程保存为 `.rpshop`；打开的原生文档可保存回 `.rp` / `.rplib`。也可导出 HTML 后直接在浏览器打开。

## 浏览器预览

预览会在默认浏览器中打开当前页，无需先保存工程。编辑、撤销、重做、取消拖动和保存后，刷新浏览器或点击播放器“重新载入”即可读取最新快照。原生页面使用源页面标识定位，保存重建数值 ID 后仍可刷新到同一逻辑页。成功打开另一个工程或关闭编辑器会停止旧预览服务。

播放器默认隐藏目录，以 100% 显示当前页。点击顶部页名可打开页面树，目录默认宽 220 像素，可拖动右边缘调整；支持搜索、展开/收起和当前页高亮。上一页/下一页与逗号/句号按页面树顺序切页，输入框获得焦点时不会触发翻页。还提供浏览历史前进/后退、页面深链接、25%–400% 数值缩放、适应宽度、完整适应、交互热点与工具栏隐藏/恢复。

浏览器中的输入、勾选、显隐和文本变化属于原型运行态，不回写编辑工程；刷新会重置运行态。导出的单文件 HTML 使用同一播放器和页面标识，但始终是导出时的快照，刷新不会读取后续编辑内容。页面说明与调试控制台尚未实现，原生事件执行范围见上述兼容限制。点击、滑动、加载、移动、显隐、面板状态及选中事件按已支持范围分派；动画按元素和类型独立排队，连续动作无需等待动画逐条结束。移动与滚动目前支持无缓动或线性缓动，动态面板滑动使用近似曲线；高级缓动尚未逐一对齐。

| `Space` + 拖动 / 中键拖动 | 平移画布；中键为额外便捷入口 |
| `Ctrl+加号` / `Ctrl+减号` / `Ctrl+0` | 放大 / 缩小 / 100% |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+9` | 居中画布 / 适配选择 / 居中选择 / 移至原点 |
| `F5` | 在默认浏览器预览当前页 |
| `Esc` | 结束文本弹窗、取消绘图或拖动 |

输入文本时，画布编辑快捷键会让位于文本输入。Enter 进入元件编辑、Tab/Shift+Tab 元件遍历、全部工具与容器修饰键尚未覆盖；高精度触控板手感、参考缩放动画和可配置移动量仍需核对。系统剪贴板的元件数据用于 RPShop 窗口之间，不声明与其他编辑器元件剪贴板格式互通。

## 构建与示例

```powershell
cargo build --locked --release
New-Item -ItemType Directory -Force .\dist | Out-Null
Copy-Item .\target\release\rpshop.exe .\dist\rpshop.exe
```

本次已验证的发布程序位于 `dist/RPShop-0.6.0-windows-x64/rpshop.exe`，便携包为同名 ZIP；[验证记录](docs/validation.md)包含版本及哈希。Logo 会嵌入 Windows 可执行文件；品牌文件在 [assets/branding](assets/branding/README.md)。

生成可重新编辑的示例工程、交互 HTML 和首张页面 SVG：

```powershell
cargo run --locked -- --export-demo .\examples
```

输出为 `examples/welcome.rpshop`、`examples/welcome.html` 和 `examples/welcome.svg`。重新生成会覆盖这三个示例文件。

生成桌面截图：

```powershell
cargo run --locked -- --screenshot .\docs\screenshots\editor.png
```

截图模式使用欢迎示例，写入图片后退出；正常启动会恢复本机会话。

打开 [组件操作示例](examples/operations.rpshop)，可查看旋转、直线与组合；[交互创建示例](examples/interactions.rpshop) 展示页面载入、连续显隐/文本动作及页面跳转。

组件画廊可直接打开 `examples/library.rpshop`，或用浏览器打开 `examples/library.html`。运行 `cargo run --locked --example library-showcase -- examples` 可按当前目录重新生成画廊。

## 项目结构与许可

`src/model.rs` 定义本地工程与校验，`src/ui.rs` 与 `src/ui_*.rs` 实现桌面编辑器、分区和元件绘制，`src/rp_format` 读取和写回 RP 原生文件，`src/preview.rs` 提供本机内存预览，`src/export.rs`、`src/player.*` 与 `src/prototype.js` 生成 HTML 播放器、原生交互运行时及 SVG，`docs` 保留调查、路线图与截图。项目目录、文件名及主界面使用 RPShop 或中性格式命名。运行不依赖原厂编辑器安装目录，工程与播放器实现独立编写，品牌资产为原创。
